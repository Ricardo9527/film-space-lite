# Film Space Lite 使用说明

## 安装和启动

Mac：解压 `Film Space Lite.app.zip`，将 `Film Space Lite.app` 拖入 `/Applications`，双击图标。此本地预览包为 ad-hoc 签名，尚未公证；系统拦截时可从 Finder 右键“打开”。完整版继续使用自己的 App。

Windows 11 x64：解压整个目录，双击 `安装到本机.cmd`。安装到当前用户的 LocalAppData/Programs/Film Space Lite，并创建桌面图标。也可保留完整目录，直接打开 `Film Space Lite.exe`。包内包含 Node 和 FFmpeg，不需要 Python。**此包尚未在 Windows 实机验收。**

图标等待服务就绪后打开默认浏览器。重复点击复用服务。关闭网页不会关闭服务；Edit 顶栏的“退出服务”先保存项目再退出。再次点击图标可恢复。

后续由 Codex 完成的产品修改会同步更新安装包与本机 Lite App。升级前先保存当前页面，更新后验证实际安装版本。

## MCP

首次启动自动生成独立插件与 MCP 配置：

- Mac：`~/Library/Application Support/Film Space Lite/MCP/film-space-lite`
- Windows：`%LOCALAPPDATA%/Film Space Lite/MCP/film-space-lite`

将该目录作为本地插件加入支持本地插件的客户端，或使用同目录上一级 `mcp-config.json` 配置 MCP。配置已写入包内 Node 的绝对路径；移动安装目录后重新启动图标刷新配置。MCP 名称为 `film_space_lite_mcp`，完整版插件可同时保留。

Agent 先读取项目和 revision，再原子提交语义操作。默认人物就是抽象人。用截图与指定时间镜头抽帧确认空间和运镜。MP4 由使用者在网页 Export 界面点击“生成 MP4”。

## 新建可移动物体（本机试用）

在左侧「对象」页点击「＋ 物体」，填写名称、外形、尺寸和颜色描述，点击「开始制作」。本机 Codex 使用现有登录和默认模型生成基础几何外形；生成进度显示在右侧，可停止。完成后沿用走位、整体比例、面向、倾斜和物体帧。

选中物体，点击「在 Codex 中继续修改」回到原聊天。例如“把船帆改成红色，其他保持”。该聊天继续修改同一物体，已有运动和关键帧保留。需在 Codex 中连接本机 Lite MCP；本机试用环境已配置。复制物体或项目后，使用「开始制作」建立独立聊天。

## 新建项目

新建时填写项目名称、画幅、帧率和时长。默认 16:9、30 fps、20 秒；画幅支持 16:9、9:16、1:1、4:3、21:9，并作为新镜头默认值保存。输出固定 1080 像素短边：横屏 16:9 为 1920×1080，竖屏 9:16 为 1080×1920。

## 文件和输出

在项目管理中打开、复制、导入、导出或删除本机 Lite 项目。项目包扩展名为 `.filmspace-lite`，与完整版项目隔离。
环境用浏览器上传 GLB。参考图、布景贴图用浏览器上传 PNG/JPEG/WebP。Export 中选择输出文件夹后生成 MP4，逐帧阶段可取消。关闭逐帧导出页面会清理任务，服务仍保留。

数据位置：Mac 为 `~/Library/Application Support/Film Space Lite`；Windows 为 `%LOCALAPPDATA%/Film Space Lite`。Projects、Logs 与 director-service.json 都在此处。镜头输出存在使用者选择的文件夹。

保留现代 Chrome、Edge、Safari 为目标浏览器；各平台实际验收状态见工作线。大场景与目标低内存机器未完成实测前不承诺最低配置。

Edit 中可点击走位列表的起点/到达点，或视口路径点；高度控件显示当前点名与编号。暂停和播放结束后可直接改单点 Y，无需 Reset；右侧演员“整体位置与初始面向”调整整体路径位置。

## 人物帧

选中演员，在时间轴跳到要调整的时刻，修改“动作内偏移与姿态”中的偏移、朝向偏移、倾斜或展开“姿态参数”，点击下方“添加人物帧”；同一时刻已有帧则为“更新人物帧”。K 同样可以记录。修改时先预览，Esc 或“取消调整”放弃；切换时间、对象、工作区、保存或播放会记录当前调整。“整体位置与初始面向”XYZ 仍调整整体路径；单点高度在走位起点/到达点调整。

菱形在原演员轨道上，可直接拖动。Shift 点击选中两帧间的区间；“全选”或 Cmd/Ctrl+A 选中当前演员全部人物帧后一起拖动。方向键逐帧微调，Delete 删除选中人物帧，撤销可恢复；0 秒帧也可移动和删除。

“上身前倾”可表达鞠躬，“头部俯仰”正值低头、负值抬头；坐下/站立与腿部形态由停留动作决定，基准路径由走位决定；人物帧记录相对路径的动作内偏移，以及方向、倾斜、上身前倾和头部俯仰。修改单个字段只记录该字段；直接按 K 添加帧记录当前偏移及姿态参数。用两个相同姿态的帧保持动作，再用下一帧完成过渡。默认平滑过渡，可选缓入缓出或线性；帧间距就是动作过渡时间。MCP 只写需要控制的姿态参数，朝向偏移为零时仍随走位自动转向。

K 与时间轴录帧按钮跟随当前栏内选中的人物、运镜或机位，分别录人物帧、镜头帧或写入机位构图。未选中或选中布景时按钮置灰，K 提示先选择对象；播放时不写入。

输出工作区名称为 Export。场景设置的“网格地面”同时控制 Edit、Export 预览与 MP4；关闭开关时三者都隐藏地面。

机位构图状态显示“已保存 / 未保存”；有调整时按钮为“保存当前构图”，保存后为灰色“构图已保存”。机位检查器、时间轴按钮与 K 使用同一保存状态。

新建几何布景默认不透明；需要透明效果时再调整层、组、对象或部件的不透明度。

### 起跳与回位

在起跳前记零偏移帧；腾空时调整 Y 上下及 X 左右/Z 前后偏移，并设置倾斜，再记录人物帧。偏移相对当前走位方向，单位米，不受人物缩放影响。到落地时刻点击“回到走位基准”，会立即写入零偏移帧，从前一个相应通道关键帧平滑过渡；勾选“同时恢复直立”会同时归零前后/左右倾斜，朝向偏移同时归零，站坐保持既有规则。间隔决定回落时长；要保持腾空，先记录一帧相同偏移。

初始面向在上方“整体位置与初始面向”中设置，不记入人物帧，也不旋转路径。下方“朝向偏移”以自动面向为基准：0° 自动，30° 在自动方向上偏转 30°，180° 背向前进。停留指定面向依旧生效。录下零偏移人物帧不会锁住后续 Move；归零按相邻该通道关键帧间隔过渡。

坐姿与站姿统一以脚下地面为走位原点；坐姿臀部位于原点后方。既有时间融合保持脚下位置，臀部向前上方回到站姿。

Edit 与 Export 工具栏常驻「? 帮助」，点击打开快捷键说明；也可按 ?（Shift + /），按 Esc 或关闭按钮返回。

## 摄影机方向关键帧

普通录帧会明确保存当前方向状态：自由朝向或既有锁定目标。后一个锁定帧从前一个明确方向帧开始转向，在自身时间精确到达。例：0 秒、3 秒普通录帧，5 秒锁定，转向发生在 3–5 秒。选中 3 秒帧并点击「恢复沿用上一关键帧」，它才不再作为方向边界，转向改为 0–5 秒。重录已有帧保留此前的方向状态选择。方向锁定栏显示所选到达帧的转向区间。

### MCP 简单人物动作

告诉 Agent 人物、动作顺序和大致节奏即可。


通过既有 `add_stay` / `insert_stay_before` 的 options 或 `update_motion_action` 的 patch 编排，无新增 UI。
`gesture`：`kneel` 双膝跪、`crouch` 蹲、`sit` 坐、`stand` 站起、`hold` 保持上个动作姿态。
`joints`：`torsoPitch/torsoYaw/torsoRoll`、`headPitch/headYaw/headRoll`、`hipBend/kneeBend`；单位弧度，范围由发现 schema 给出。正俯仰向前/低头，负值后仰/抬头；正 headYaw 朝人物左侧（人物局部 +X），头部角度相对腰部。髋膝控制两腿同步。
`duration` 包含过渡和停顿，`transitionSeconds` 指定到达目标姿态的时间，默认 0.25 秒并限制在本段内，0 为立即到达。首次手势从站姿开始。手势只修改指定关节，腿部预设保持已有头腰状态；后续 hold 继承跪姿。普通站坐 Hold 或 Move 仍恢复既有动作姿态。已存在的 torsoPitch/headPitch 人物帧是显式覆盖；Agent 编排前检查这些通道，避免意外覆盖动作。
修改 joints 是替换该动作的稀疏关节目标，空对象清除本段覆盖。通过 UI 明确选择站坐时清除该段手势/关节覆盖。

例：两秒跪下、停一秒；一秒抬头、停一秒；一秒向左转头、停一秒：

```json
[
  {"action":"add_stay","actorID":"person","options":{"gesture":"kneel","duration":3,"transitionSeconds":2}},
  {"action":"add_stay","actorID":"person","options":{"gesture":"hold","joints":{"headPitch":-0.5},"duration":2,"transitionSeconds":1}},
  {"action":"add_stay","actorID":"person","options":{"gesture":"hold","joints":{"headYaw":1.0},"duration":2,"transitionSeconds":1}}
]
```

动作保存到同一项目，确定性采样供 Edit、Export、跟焦/瞄准与 MP4 使用；关节操作通过同一命令验证、revision 与语义撤销链路。

### 摄影机视角遮罩

C 切换自由视角与选中的 Shot View / Still View。进入摄影机视角后，V 切换框外遮罩；自由视角按 V 保持当前画面。

## 检查与安装更新

打开软件后，后台会检查并下载对应平台的完整更新包，顶部显示下载进度。下载校验完成后，所有页面已保存且连续五分钟没有操作、播放、导出等工作结束后会静默更新。正常关闭全部页面后，服务经过三十秒安静期也可完成更新。刷新和临时断线会等待页面重新连接确认。

需要马上安装时，在提示或帮助中点击「立即更新」。先保存当前编辑和机位草稿；其他页面也需空闲。更新过程中暂时锁定编辑，完成后自动重启并回到项目。项目数据保存在原位置。网络、权限或启动失败会显示具体原因，安装替换失败时恢复旧版；手动检查可重试。帮助保留版本、手动检查、更新说明与发布页入口。

先安装带自动更新功能的版本，后续发布即可后台下载和空闲安装。源码运行使用发布页手动安装。

## 动作与移动面向

停留与移动都直接显示「面向」，可输入小数或拖动，修改即使用指定角度。点击「保持面向」恢复进入该段时的方向。移动的「跟随移动」随路径更新；停留的「朝向移动」按下一段移动方向设置角度，路径修改后可再次点击对准，没有后续移动时置灰。自动状态仍显示计算出的角度。

角度是动作基准面向；人物帧的朝向偏移作为额外旋转，零值使用动作面向。移动的左右/前后位置偏移仍相对走位方向。入口沿用短暂平滑转向。

冲刺后被打飞：冲刺段跟随移动方向，被击飞段选择保持面向，再用人物帧调整腾空和后仰。

制作失败后点击「重试制作」，会继续原聊天；已完成的物体可点「继续制作」。停止失败时，本地忙碌状态会释放，界面保留原因；请在原 Codex 聊天确认任务状态。

## 导出当前帧

进入 Export，暂停到需要的时间，点击「导出当前帧」。填写图片名称后点击「导出 PNG」；尚未设置输出文件夹时先选择文件夹。PNG 使用当前 Shot 画幅与固定 1080 短边，同名图片自动增加版本号。可点「在文件夹中显示」找到结果。

## Bodycam 身体绑定

运镜「对准」提供独立 Bodycam 身体绑定，选择人物后保留当前构图；「重置到胸前」才切换到身体前方、镜头回拍人物脸部与上身的支架机位。绑定跟随躯干与整体三轴姿态，头部单独旋转不影响；手持效果继续叠加。绑定期间原位置跟随与方向锁定停用并保留参数，关闭后恢复普通轨道。调整位置、朝向后记录关键帧，保存相对身体的机位；同一人物的安装位姿帧沿用相机插值规则。普通世界环绕在关闭 Bodycam 后生成。目标删除时明确提示并使用普通轨道。

方向锁定新开启时采用「精确锁定（推荐）」；连续平滑可选，旧关键帧的响应值保留。

移动与停留提供“转向”时长，单位秒，默认 0.25；0 为立即转向，实际时长不超过该段时长。进入该段后从承接的基准朝向转至目标，移动同步进行，不延长动作。保持面向时不发生该转向，控件置灰并保留值。人物帧朝向偏移、姿态过渡和位置偏移基准保持独立；Bodycam 跟随求值后的身体方向。
